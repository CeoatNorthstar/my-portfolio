# naol.me

Personal site of Naol Demisse, independent researcher in particle physics,
quantum mechanics and special relativity.

A minimal business-card home with a blog and a papers section beside it, an
in-page PDF reader with highlights, anonymous comments, and a small console
for publishing. There are a few things hidden for curious visitors.

**Stack:** React (CRA) + Tailwind + Framer Motion on Cloudflare Pages, with Pages
Functions over D1 (data) and R2 (media and PDFs). pdf.js for reading and for
pulling title, abstract and references out of uploaded papers.

Setup, local development and deployment: see [`SETUP.md`](./SETUP.md).
